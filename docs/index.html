Perguntas frequentes

Ou busque na central de ajuda →

É grátis?

Sim. O app é gratuito e funciona 100% offline sem conta. Recursos de família compartilhada (online) são pagos à parte, quando disponíveis.

Preciso de internet?

Não para usar o app: finanças, mercado, combustível, metas e dízimo funcionam offline. Internet só é necessária para a IA e para a versão online.

Meus dados vão para a nuvem?

Não. Sem login, nada sai do aparelho. O backup é feito por você via exportação CSV.

Tem para iPhone?

Hoje o app é distribuído para Android (APK) e Web (PWA, que funciona no iPhone pelo Safari). Versão iOS na App Store está em avaliação.

Como funciona a IA?

Você cadastra sua chave de um dos 5 provedores (OpenAI, Gemini, Anthropic, OpenRouter ou Zen). O app injeta seus dados no prompt com proteção anti-injection e tenta outro provedor se um falhar.
